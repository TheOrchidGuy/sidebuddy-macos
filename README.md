# Side Buddy Mac v0.3

A tiny local Electron app for saving snippets, terminal commands, setup notes, and copy/paste reminders.

## What it does

- Save notes and terminal commands
- Categorize notes
- Search saved notes
- Copy a note body to clipboard
- Edit notes
- Delete notes
- Stores data locally on your Mac in Electron's app user data folder

## How to run it

Open Terminal and run:

```bash
cd ~/Desktop/side-buddy-mac-v0.3
npm install
npm start
```

If you already have Node and npm installed, this should launch the app.

## Notes

This zip does not include `node_modules` because that folder is large and machine-generated.
Run `npm install` once after unzipping.
